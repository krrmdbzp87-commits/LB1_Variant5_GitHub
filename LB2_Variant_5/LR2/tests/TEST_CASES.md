## Умови локальної перевірки

- Компілятор: GNU g++ 14.2.0.
- Прапорці: `-std=c++17 -Wall -Wextra -pedantic`.
- Основна програма: сценарії 1–9 пройшли перевірку введення та підсумкової статистики.
- D1: дефектна програма навмисно повертає код 1 на пороговому тесті; виправлена програма повертає код 0 на трьох regression-тестах.
- Це не замінює обов'язкову демонстрацію в Visual Studio: встановлення breakpoint, крокування F10/F11 та перегляд значень у Watch.
