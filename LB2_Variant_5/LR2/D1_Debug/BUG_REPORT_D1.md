# Bug report — D1: невключний поріг у лічильнику

## Ідентифікація

- Лабораторна робота: № 2 — «Потокова обробка даних»
- Варіант: 5
- Призначений дефект: D1
- Компонент: окрема тестова функція `countAtLeast`
- Тип дефекту: логічна помилка граничної умови

## Контракт

Функція має зараховувати значення, яке **дорівнює порогу або перевищує його**. Для `value = 50` і `threshold = 50` очікуваний результат — `1`.

## Кроки відтворення

1. Відкрити окремий тестовий проєкт `01_Buggy`.
2. Встановити breakpoint на умову `if (value > threshold)`.
3. Запустити проєкт у Debug-конфігурації та передати `value = 50`, `threshold = 50`.
4. Перевірити аргументи та результат функції.

## Очікуваний і фактичний результат

| Параметр | Значення |
|---|---:|
| `value` | 50 |
| `threshold` | 50 |
| Очікувано | 1 |
| Фактично до виправлення | 0 |

## Причина

Оператор `>` виключає рівність. Умова не відповідає включному контракту.

## Виправлення

Замінити `value > threshold` на `value >= threshold`. Інші частини функції не змінюються.

## Regression-перевірки

| Вхідні дані | Очікувано | Що перевіряється |
|---|---:|---|
| `49, 50` | 0 | Значення нижче порогу |
| `50, 50` | 1 | Рівність порогу |
| `51, 50` | 1 | Значення вище порогу |

Виправлена тестова версія міститься в `02_Fixed/main.cpp`.
