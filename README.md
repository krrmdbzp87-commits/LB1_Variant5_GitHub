# Лабораторна робота № 1 — Лінійні та розгалужені алгоритми

- **Дисципліна:** Основи програмування
- **Група:** ІІТ-26-1
- **Варіант:** № 5 — «Результат з умовним штрафом за пропуски»
- **Мова програмування:** C++
- **Стандарт:** C++17

## Призначення програми

Програма обчислює штраф за кількість пропусків, віднімає його від базового результату та не дозволяє скоригованому результату стати меншим за нуль. Після обчислення програма визначає, чи досягнуто поріг у 50 балів.

## Вхідні дані

Програма зчитує два цілих числа в такому порядку:

1. `base` — базовий результат у балах, від `0` до `100` включно.
2. `absences` — кількість пропусків, від `0` до `10` включно.

Введіть числа через пробіл або з нового рядка, наприклад:

```text
74 4
```

Якщо дані не вдалося прочитати або будь-яке значення виходить за допустимі межі, програма виводить повідомлення про помилку та завершується з ненульовим кодом.

## Формули та правила

- `penalty = 3 * absences`
- `adjusted = max(0, base - penalty)`
- якщо `adjusted < 50`, виводиться **«Нижче порога»**;
- якщо `adjusted >= 50`, виводиться **«Поріг досягнуто»**.

Рівно 50 балів належить до гілки **«Поріг досягнуто»**.

## Алгоритм (псевдокод)

```text
Початок
  Прочитати base та absences
  Якщо читання неуспішне — повідомити про помилку та завершити програму
  Якщо base не належить [0; 100] — повідомити про помилку та завершити програму
  Якщо absences не належить [0; 10] — повідомити про помилку та завершити програму
  penalty = 3 * absences
  adjusted = max(0, base - penalty)
  Вивести penalty та adjusted
  Якщо adjusted < 50:
    Вивести «Нижче порога»
  Інакше:
    Вивести «Поріг досягнуто»
Кінець
```

## Збірка та запуск у VS Code на macOS

1. Відкрийте папку проєкту `LB1_Variant5_GitHub` у VS Code.
2. Відкрийте Terminal → New Terminal.
3. Переконайтеся, що термінал перебуває в папці, де розташований `main.cpp`.
4. Скомпілюйте програму:

   ```bash
   g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o main
   ```

   Якщо у вашій системі використовується `clang++`, команда також підійде із заміною `g++` на `clang++`.

5. Запустіть програму:

   ```bash
   ./main
   ```

6. Введіть, наприклад, `74 4` і натисніть Enter. Програма обробить введені два числа та виведе результат.

## Приклад запуску

Вхідні дані:

```text
74 4
```

Результат:

```text
Штраф: 12
Скоригований результат: 62
Поріг досягнуто
```
